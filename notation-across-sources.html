Notation Across Sources

This page sets our notation beside the notation of Hutchinson’s and Harris’ lecture notes and five textbooks. The Notation Choices page gives the reasons for our conventions; this page lists the symbols side by side. The data are in data/notation-conventions.csv and data/symbols-used.csv. Links in the tables go to the definitions in the DATA 571 notes, with a few to the statistics and math prerequisite notes.

Sources

The tables on this page set our notation beside the notation of these sources:

  • Brian Hutchinson’s lecture notes for DATA 471/571 [1].
  • Kameron Decker Harris’ 2022 weekly notes for DATA 471 [2].
  • An Introduction to Statistical Learning, or ISL, in its R edition [3] and its Python edition [4]. They share one column because the two books use the same notation: their notation sections are word for word the same, and so are the symbols for the slack variable, the budget \(C\) and the learning rate.
  • The Elements of Statistical Learning, or ESL [5].
  • Learning From Data, or LfD [6].
  • Bishop’s Pattern Recognition and Machine Learning [7].
  • Murphy’s Probabilistic Machine Learning: An Introduction [8].

To read the tables:

  • A dash means the source has no symbol for the concept or does not cover it. The printed chapters of LfD, for example, stop before neural networks and SVMs.
  • A cell is bold where the source writes the symbol in bold, and plain where the source does not. Hutchinson’s notes write vectors as plain letters, and Harris’ notes put an arrow over them.
  • The name of each source in a table header links to its entry in the reference list.
  • A row label links to the definition in these notes where there is one.

Differences that cause confusion

Six differences cause most of the confusion when you read across sources:

  • Labels: the two-class label is \(\{0, 1\}\) for logistic regression and \(\{-1, +1\}\) for SVMs in most sources, and always \(\{-1, +1\}\) in LfD.
  • The SVM constant \(C\): Hutchinson, Bishop and Murphy use \(C\) as a penalty on the slack, so a larger \(C\) allows fewer violations. ISL uses \(C\) as a budget on the slack, so a larger \(C\) allows more.
  • Sample index: a superscript in parentheses (\(x^{(i)}\)) in Hutchinson’s notes, a subscript \(i\) in ISL and ESL, and a subscript \(n\) in LfD, Bishop and Murphy.
  • Prediction of the fitted model, averaged over data sets: these notes write the prediction at \(x\) as \(\predvalf{x}\), as ISL and ESL do (\(\hat{f}(x)\)). Where \(x\) is fixed and its dependence is not the point, as in the bias–variance decomposition, they drop the argument and write \(\predval\). Either way the prediction is a random variable, because it depends on the training set. The average fit \(\avgfitf{x}\) is the population expectation of that prediction over training sets, written with no bar and no hat.
  • Target: Bishop calls the output \(t\) for target, and every other source calls it \(y\).
  • Subscripts and parentheses: which arguments go in a subscript and which in parentheses varies, as in \(f_\theta(x)\) versus \(f(x; \theta)\). The Notation Choices page states our convention and the alternatives.

Other symbols used

The side-by-side tables show the symbols that differ between sources. This table lists every other symbol that a chapter of these notes uses, with what it means. Where a symbol takes arguments, the letters \(a\), \(b\) and so on stand in for them.

symbols_used <- utils::read.csv(
  "data/symbols-used.csv",
  stringsAsFactors = FALSE,
  encoding = "UTF-8",
  na.strings = character(0)
)
symbols_used$meaning[is.na(symbols_used$meaning)] <- ""
symbols_table <- data.frame(
  Symbol = sprintf("$%s$", symbols_used$symbol),
  Meaning = gsub("|", "\\|", symbols_used$meaning, fixed = TRUE)
)
knitr::kable(
  symbols_table,
  format = "pipe",
  caption = "Other symbols used in these notes {#tbl-symbols-used}"
)
